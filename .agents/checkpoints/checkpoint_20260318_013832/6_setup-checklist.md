# Setup Checklist

Чеклист адаптирован из `kb_agent_instructions.docx` под текущий репозиторий.

- [x] Создать `workspace/` как единую папку для Obsidian и агентного харнеса.
- [ ] Открыть `workspace/` в Obsidian как отдельный vault.
- [ ] Установить Community Plugins `Terminal` и `Kanban`, если они нужны в локальном workflow.
- [ ] Включить Obsidian Command Line Interface в `Settings -> General`.
- [x] Создать `workspace/agents.md`.
- [x] Создать папку `workspace/skills/` и базовые skills.
- [x] Создать папку `workspace/assets/` и базовые шаблоны.
- [ ] Запускать агентный харнес из `workspace/`, а не из корня репозитория, когда задача касается базы знаний.
- [ ] Проверить, что `obsidian --help` работает в терминале.
- [ ] Проверить, что агент видит `workspace/agents.md` и умеет следовать правилам vault.
