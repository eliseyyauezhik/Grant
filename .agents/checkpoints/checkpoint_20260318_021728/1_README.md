# Projects Area

Папка `projects/` хранит активные рабочие документы, task boards, daily logs и `.base` views, которые работают как интерфейс к данным из Markdown-заметок.

## Start Here

- [[projects/task-inbox]]
- [[projects/services.base]]
- [[projects/sources.base]]
- [[projects/runbooks.base]]

## Rules

- Для новых задач используй `[[assets/task-template]]`.
- Для задач из неструктурированного текста сначала читай `[[skills/capture-skill]]`.
- Для операционных ежедневных записей используй `projects/daily/` и `[[assets/daily-template]]`.
- Когда материал стабилизировался и стал долгоживущим знанием, переноси итоговую заметку в `notes/`.
