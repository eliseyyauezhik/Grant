# Review Skill

Используй этот скил, когда пользователь просит проанализировать заметку, тему или группу связанных материалов внутри vault.

## Workflow

1. Начни с целевой заметки или тематического индекса.
2. Если доступен `obsidian` CLI, проверь исходящие и входящие связи через `obsidian link-path` и `obsidian backlink-path`.
3. Если CLI недоступен, найди wikilinks и упоминания через поиск по Markdown-файлам.
4. Прочитай только релевантные заметки, а не весь vault подряд.
5. Сформируй вывод по четырем блокам: текущее состояние, пробелы, связи с другими темами, следующие шаги.

## Правила

- Отделяй факты из заметок от собственных выводов.
- Указывай, какие заметки являются ключевыми.
- Если связи отсутствуют, прямо предлагай, какие wikilinks стоит добавить.
