# Official Obsidian Bases Help

## Summary

Официальная документация по Bases: `.base` файлы, filters, formulas, views и работа поверх Markdown + properties.

## Key Facts

- `.base` является нативным поддерживаемым форматом Obsidian.
- Bases работают поверх локальных Markdown-файлов и их properties.
- Представления описываются YAML-синтаксисом.

## Usage

- Источник истины для реестров сервисов, источников и runbooks в этом vault.
