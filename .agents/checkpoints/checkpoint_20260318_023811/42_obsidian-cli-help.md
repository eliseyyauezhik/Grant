# Official Obsidian CLI Help

## Summary

Официальная документация по CLI Obsidian: команды, параметры, требования к installer и поведение на Windows.

## Key Facts

- Для Windows нужен installer `1.12.4+`.
- CLI требует работающий экземпляр приложения.
- Если терминал запущен не из vault, можно использовать `vault=<name>`.

## Usage

- Источник истины для CLI-процедур и проверок сервиса `[[notes/services/obsidian-workspace-cli]]`.
