# Obsidian Terminal Plugin

## Summary

Исходный источник по plugin `terminal`: профили терминала, integrated/external modes и хранение plugin settings в `.obsidian/plugins/terminal/data.json`.

## Key Facts

- Plugin поддерживает external и integrated terminals внутри Obsidian.
- Конфигурация профилей хранится локально в `workspace/.obsidian/plugins/terminal/data.json`.
- На Windows для части integrated возможностей plugin рекомендует Python-зависимости.

## Usage

- Источник истины для сервиса `[[notes/services/obsidian-terminal-shell]]`.
