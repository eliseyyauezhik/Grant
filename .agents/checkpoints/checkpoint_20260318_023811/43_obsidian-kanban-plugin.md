# Obsidian Kanban Plugin Docs

## Summary

Основной источник по markdown-backed kanban boards в Obsidian: board format, commands и поведение plugin view.

## Key Facts

- Плагин использует frontmatter `kanban-plugin: board` для board files.
- Доска хранится в Markdown и остается частью обычного vault content.
- Плагин добавляет команды для создания board, archive completed cards и переключения представлений.

## Usage

- Источник истины для сервиса `[[notes/services/obsidian-kanban-ops-board]]`.
