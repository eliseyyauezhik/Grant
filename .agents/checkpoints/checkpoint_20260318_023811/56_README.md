# Binary Assets

Эта папка предназначена только для бинарных вложений, которые нельзя хранить как Markdown.

## Rules

- Не использовать эту папку как основное хранилище знаний.
- Для каждого важного бинарного файла сначала или сразу после добавления создать Markdown-заметку с контекстом и ссылками.
- По возможности держать оригиналы вне vault, а здесь хранить только минимально нужные вложения.
