# Kanban Skill

Используй этот скил, когда нужно превратить список задач, переписку или транскрипт в структурированный task board.

## Перед началом

1. Прочитай `[[assets/task-template]]`.
2. Найди существующую доску в `projects/`.
3. Если доски нет, используй `[[projects/task-inbox]]` как стартовую точку.

## Формат карточки

- Заголовок должен быть коротким и проверяемым.
- Одна карточка равна одному результату.
- Добавляй исполнителя и проектный тег, если они понятны из контекста.
- При необходимости создавай отдельную заметку-задачу по шаблону и связывай ее wikilink-ссылкой.

Рекомендуемая строка карточки:

`- [ ] Краткое действие | @owner | #project/<slug>`

## Колонки по умолчанию

- `Backlog` для новых задач.
- `This Week` для ближайших действий.
- `Blocked` для зависимых задач.
- `Done` для завершенных задач.

## Правила

- Пиши на русском языке.
- Не смешивай несколько задач в одной карточке.
- Если источник неструктурированный, сначала нормализуй формулировки, затем раскладывай по колонкам.
- Если задача ссылается на знания, добавляй wikilinks на заметки из `notes/`.
