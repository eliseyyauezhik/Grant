# Project Intake Protocol

## Триггер

Запускать если: пользователь описывает новую идею без spec-файлов,
или явно говорит "новый проект" / "хочу сделать".

## Правило

НЕ начинать писать код. Задать ровно 5 вопросов:

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🚀 НОВЫЙ ПРОЕКТ — 5 вопросов

1. КТО ПОЛЬЗОВАТЕЛЬ И КАКАЯ БОЛЬ?
   Кто использует и что перестаёт быть проблемой?

2. MVP — ЧТО МИНИМАЛЬНО ДОСТАТОЧНО?
   Какие 1-2 функции делают продукт уже полезным?

3. ОГРАНИЧЕНИЯ?
   Технические, юридические или бизнес-ограничения?

4. КРИТЕРИЙ УСПЕХА?
   Как поймём что MVP работает?

5. СРОЧНОСТЬ?
   Эксперимент за выходные или проект на месяцы?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## После ответов

1. Создать .agents/steering/product.md
2. Предложить стек в .agents/steering/tech.md — ждать одобрения
3. Предложить первый spec для ключевой фичи
4. Спросить "Начинаем?" — действовать только после ответа
