## Что предложено (12-месячная кампания)

### 1. «Золотая партия» (OEE + геймификация)
- Смены с OEE > 85% = «Золотые партии» → виртуальные км
- Цель: собрать 400 партий по всему заводу
- Визуал на цеховых экранах: КАМАЗ проезжает через эпохи города
- **Оценка для юбилея:** ⭐⭐⭐ — хорошо для Q1-Q2, создаёт предъюбилейный фон
- **Ограничение:** требует KORA.Pulse (цифровая платформа), которой может ещё не быть

### 2. «Страж безопасной смены» (HSE)
- Проактивные отчёты об опасностях = баллы
- Уровни: Разведчик → Авангард → Центурион (золотая спецодежда)
- Цель: 3500 наблюдений (отсылка к 35 годам)
- **Оценка для юбилея:** ⭐⭐⭐ — долгоиграющий, но нужна инфраструктура KORA.Life

### 3. «Ретро-инновации» (Кайдзен)
- Найти процесс, не менявшийся с 90-х → предложить цифровое решение
- Формат «Тогда и Сейчас» (1995 бумага vs 2026 планшет)
- Бонус: 35 000 руб. победителям
- **Оценка для юбилея:** ⭐⭐⭐⭐⭐ — ОТЛИЧНО! Можно запустить без цифровой платформы, чистый сторителлинг

### 4. «Совместный путь» (B2B, KORA.Connect)
- Виджет-таймлайн: точки интеграции КОРА с КАМАЗом
- Счётчик «15 миллионов деталей»
- «Серия качества» — дни подряд с 0 PPM брака
- **Оценка для юбилея:** ⭐⭐⭐ — нужна для VIP-части (партнёры КАМАЗ/ГАЗ)

### 5. «Голос мастеров» (Видео-вики)
- Ветераны записывают 2-мин видео о секретах конкретных станков/форм
- «Моя самая трудная смена» — истории кризисов 90-х и 00-х
- AI-тегирование для поиска
- Статус «Легенда КОРА» (золотая рамка аватара)
- **Оценка для юбилея:** ⭐⭐⭐⭐⭐ — ГЛАВНАЯ ЖЕМЧУЖИНА! Уникальный контент, создаёт наследие

**«Голос мастеров» + «Ретро-инновации» = ядро юбилейной кампании.**
Они не требуют цифровой платформы, создают уникальный контент, вовлекают ветеранов и молодёжь.
Остальные механики — бонус, если KORA.Pulse/KORA.Life будут готовы.
