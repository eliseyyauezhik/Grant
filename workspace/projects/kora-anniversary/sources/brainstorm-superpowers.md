# Superpowers Brainstorm

## Goal
Создать цифровую экосистему для Группы КОРА, которая позволит сотрудникам удобно (голос/фото/текст) сообщать о проблемах и идеях, а руководству — получать очищенную и структурированную суть этих данных для принятия управленческих решений.

## Constraints
* **Интеграция:** Решения должны вписываться в существующую "Цифровую нить" (Kafka, KORA.Life), описанную в стратегии.
* **Удобство:** Интерфейс должен быть предельно простым (Mobile-First), поддерживать мультимодальный ввод (Voice, Media).
* **Качество:** Превращение неструктурированных данных в четкие задачи/инсайты (LLM/NLP).
* **Безопасность:** Защита данных сотрудников и коммерческой тайны.

## Known context
* **Компания:** Производитель автокомпонентов Группа КОРА.
* **Стратегия:** KORA.Life (HR/Kaizen), KORA.Pulse (IIoT), KORA.Connect (B2B) уже в планах.
* **Проблема:** Разрыв коммуникации между цехом и офисом ("испорченный телефон"). Данные теряются или искажаются.
* **Стек:** Kafka, Go, Python (ML), Flutter.

## Risks
* **Низкое вовлечение:** Рабочие могут игнорировать сложные приложения, если польза неочевидна.
* **Шум:** Поток жалоб может перегрузить систему, если фильтрация (AI) не справится.
* **Галлюцинации AI:** Риск искажения смысла при автоматическом саммаризации.
* **Бюрократия:** Если на каждый инсайт нужно заполнять 10 полей, никто не будет писать.

## Options

### Option 1: Модуль "KORA.Voice" (Инсайты через голос)
Интеграция в KORA.Life функции быстрой подачи инсайтов.
* **Механика:** Большая кнопка "Сообщить". Удержание -> Запись голоса ("На 3-м прессе масло течет") -> AI транскрибирует -> AI категоризирует (Тег: #Оборудование, Приоритет: Высокий) -> Отправка мастеру.
* **Аналитика:** Дашборд для топ-менеджмента "Pulse of the Floor" (тренды проблем, облако слов).
* **Плюсы:** Минимальный барьер входа (не надо печатать).

### Option 2: Корпоративный TikTok "KORA.Shorts" (Визуальный обмен опытом)
Платформа для обмена короткими видео-инструкциями и проблемами.
* **Механика:** Рабочий снимает проблему на видео -> Краткое описание -> Тег. Другие могут лайкать/комментить (валидация проблемы).
* **Плюсы:** Высокая наглядность. **Минусы:** Требует модерации контента.

### Option 3: Чат-бот "Мастер-Помощник" в мессенджере (Telegram/WA)
Использование привычных мессенджеров с умным ботом.
* **Механика:** Бот периодически спрашивает "Как смена?", принимает фото/текст.
* **Плюсы:** Не нужно ставить отдельное приложение. **Минусы:** Безопасность данных во внешнем мессенджере.

## Recommendation
**Option 1: Модуль "KORA.Voice" в KORA.Life.**
Это решение идеально ложится в стратегию единого супер-аппа. Голосовой ввод снимает барьер "грязных рук" и лени печатать. AI-обработка (Whisper + LLM) позволяет превратить поток аудио в структурированную базу знаний и задач, что решает главную проблему "обработки до сути".

## Acceptance criteria
1. Разработан UI/UX концепт модуля **KORA.Voice** (экраны записи, подтверждения, ленты инсайтов).
2. Спроектирован **AI-пайплайн**: Audio -> STT -> Summarization -> Classification -> DB.
3. Определена структура базы данных инсайтов (таблицы: `insights`, `categories`, `trends`).
4. Создан прототип дашборда руководителя, агрегирующий "суть" проблем за смену/неделю.
