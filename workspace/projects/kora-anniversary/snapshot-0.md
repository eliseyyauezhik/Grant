## 4. Ключевые инсайты (обновлённые)

1. **Компания «на ладан дышит»** (дек 2025): потеря >50% объёмов. К маю 2026 — неясно. Юбилей должен учитывать оба сценария.
2. **Трёхслойная модель** (из мета-модели): Экономический → Социальный → Экзистенциальный. Юбилей = разрядка → переопределение → запуск новой нормы.
3. **Главный критерий успеха**: «Возник ли тёплый человеческий шлейф на следующее утро?»
4. **Главный риск**: псевдодуховный корпоративный театр — цинизм усиливается.
5. **Бывшие повара** — обязательно пригласить (эмоциональный якорь для ветеранов).
6. **КОРА** = Камское Общество **Развития** Автомобилестроения. «Развитие» — ключевой принцип.
7. **Психодинамика основателей** детально описана — 3 типа, 3 языка убеждения.
