## Usage

- Создавай новые сервисные записи по `[[assets/service-template]]`.
- Для каждого зрелого сервиса поддерживай как минимум один `source` и один `runbook`.
- Считай эту заметку стартовой точкой для поиска владельцев, статусов и источников истины.
