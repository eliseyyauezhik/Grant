# Source Registry

Реестр внешних и внутренних источников, на которые опираются сервисные записи.

## Main View

![[projects/sources.base#Sources]]

## Usage

- Каждая важная внешняя документация, репозиторий или API должны иметь отдельную source note.
- Для каждого источника заполняй `last_verified`, чтобы было видно, насколько информация свежая.
