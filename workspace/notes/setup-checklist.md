# Setup Checklist

Чеклист адаптирован из `kb_agent_instructions.docx` под текущий репозиторий.

- [x] Создать `workspace/` как единую папку для Obsidian и агентного харнеса.
- [x] Открыть `workspace/` в Obsidian как отдельный vault.
- [x] Установить Community Plugins `Terminal` и `Kanban`, если они нужны в локальном workflow.
- [x] Включить Obsidian Command Line Interface в `Settings -> General`.
- [x] Создать `workspace/agents.md`.
- [x] Создать папку `workspace/skills/` и базовые skills.
- [x] Создать папку `workspace/assets/` и базовые шаблоны.
- [x] Для KB-задач либо запускать агентный харнес из `workspace/`, либо при запуске из корня репозитория явно читать `workspace/agents.md` и ограничивать правки папкой `workspace/`.
